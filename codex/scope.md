# Local Dev Scope

This branch is for local full-stack development only.

Allowed work:

- Spring Boot backend source under `backend/src`.
- Next.js frontend source under `frontend`.
- Local-only environment configuration in `.env`.
- Local Docker service definitions.
- README and Codex documentation for the local-dev branch.

Out of scope:

- Remote production credentials.
- Cloud database or Redis URLs.
- Redis or OTP implementation.
- Files outside this repository.
